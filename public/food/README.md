# Food photo library

Keep restaurant photos in one folder per restaurant ID:

```text
public/food/
  0001-uluh/
    cover.webp
    02.webp
    03.webp
```

Reference them in CSV/Excel as `./food/0001-uluh/cover.webp`.

Use Ryan-owned or properly licensed images. Prefer WebP, a 4:3 crop, and a longest edge around 1600px. The first image becomes the card cover.
